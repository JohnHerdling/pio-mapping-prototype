Externe Evaluationspopulation – Synthea

Datenquelle:
Synthea – 100 Sample Synthetic Patient Records, CSV
Originaldatei:
synthea_sample_data_csv_latest.zip

Einschlusskriterien:

M1 – Körpergewicht
Mindestens eine Beobachtung mit:
DESCRIPTION = Body Weight
UNITS = kg
TYPE = numeric
und vorhandenem VALUE.

M2 – Diagnose
Mindestens ein Eintrag in conditions.csv mit vorhandenem
PATIENT, CODE und DESCRIPTION.

M3 – Medikationsinformation
Mindestens ein Eintrag in medications.csv mit vorhandenem
PATIENT, START, CODE und DESCRIPTION.

Hinweis:
Dieses Einschlusskriterium legt noch nicht fest, dass fachlich
„Medikation liegt vor“ gilt. Es stellt lediglich sicher, dass für
M3 externe Quelldaten zur Evaluation vorhanden sind.

M4 – Schmerzsymptomatik
Mindestens eine Beobachtung mit vorhandenem VALUE und einer
der folgenden DESCRIPTION-Ausprägungen:

- Pain severity - 0-10 verbal numeric rating [Score] - Reported
- Pain severity - Reported
- Pain severity in the past week - 0-10 numeric rating [Reported]

M5 – Allergien
Mindestens ein Eintrag in allergies.csv mit vorhandenem
PATIENT, CODE und DESCRIPTION.
